news.csv is a tiny synthetic demo dataset made only to test the training and app workflow.
Its examples are not real news or a source of meaningful model training or evaluation.
Do not use predictions from a model trained on this file to assess real claims.

For meaningful experiments, replace it with a legitimately obtained labelled dataset
and review its licence, provenance, class balance, duplicates, and label quality.
Required CSV columns: text,label
Expected labels: REAL and FAKE (or two consistent class names).
